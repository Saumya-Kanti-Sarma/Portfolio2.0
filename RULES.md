# Project Rules

1. Use modular architecture. Components, hooks, utils, and constants must live in their related directories inside the src folder.

2. Code that works together stays together. If a function or logic is only relevant to a specific page, place it in a separate directory inside that page's folder (for example, /home with a nested non-route directory for page-specific logic). This folder must not be exposed as a route.

3. Keep related functionality grouped by feature or page so the structure stays predictable and easy to maintain.

4. For icons use react icons.

5. Use css varibles wherever necessary.
